### ⚡ Who We Are
**RevieX** is an independent software studio focused on building clean, custom-engineered desktop applications, alternative clients, and developer tools. We design with a sharp, art-craft, black-and-white aesthetic—prioritizing performance, utility, and user control.

### 🛠️ Projects
* **[SpotX](https://github.com/RevieX)** — Custom-engineered media experiences with integrated system playback controls.
* **[SnapX](https://github.com/RevieX)** — Ghost-themed, high-performance alternative client utility.

### 💻 Tech Stack & Focus
* **Languages & Frameworks:** C#, WPF (.NET Framework 4.8), Kotlin, JavaScript, Java.
* **Architecture:** Custom window chrome, high-efficiency WebViews, and native system integrations.
* **Aesthetic:** Minimalist monochrome, vector-precise UI, and power-user workflows.
